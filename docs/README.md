#Equipos del tractor strore

#Explorer
Este equipo es el que "manda" en la navegación.

Qué hace: Muestra los tractores (nombre, precio, foto).

Filtros: Hay tres categorías fijas: All, Classics y Autonomous.

Tiendas: Tiene que haber una sección para buscar tiendas físicas con su foto para que la gente vaya a ver los tractores en persona.

Componentes compartidos: El Header y el Footer son de ellos. En el header pones los links para saltar entre "Máquinas" y "Tiendas".


#Decide
Aquí es donde el usuario elige qué va a comprar.

Detalle: Cuando entras a un tractor, se ve el precio, los colores y las fotos.

Acción: El botón de "Añadir al carrito". Cuando le das click, tiene que avisar que ya se agregó y mostrar el link a la cesta.

Mezcla: Para que no se vea vacío, arriba usa el Header de Explore y abajo le pide a Explore sus "Recomendaciones".


# Checkout

Este es el final del embudo, el que maneja el carrito y la plata.

Carrito: Muestra la lista de lo que elegiste, separando por color o modelo para que no se mezcle.

Formulario: Pide nombre, apellido y cómo lo vas a recibir (Store Pickup para elegir tienda o envío).

Flujo: Botón de "Place Order" -> Pantalla de "Gracias por tu compra" -> Botón de "Seguir comprando" para volver al inicio.
